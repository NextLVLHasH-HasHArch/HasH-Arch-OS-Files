# hasharch-software-center

HasH-Arch Software Centre — PyQt6 graphical package manager (pacman/AUR/flatpak) + tray update notifier.

Part of **HasH-Arch** — a customised KDE Plasma 6 desktop (BlackArch/Arch fork)
maintained by NextLVLHasH & Opus 4.7.

## Install
Copy the contents into the matching location on a Plasma 6 system:
- `/home/hash/.local/bin/hash-store`
- `/home/hash/.local/bin/hash-update-notifier`
- `/home/hash/.config/autostart/hash-update-notifier.desktop`
