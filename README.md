# HasH-Arch — OS Files

The OS components for **HasH-Arch** ("NextLVLHasH") — a stable, verifiable,
GPG-signed KDE Plasma 6 distro on Arch + BlackArch. Each `hasharch-*` dir is a
component (Settings, Security, Software Center, plasmoids, theme, configs).

Highlights: a Windows-11-style native Settings app, a self-healing Store/update
centre, IR-only face unlock, a Secure-Boot/TPM2 key vault, local Endpoint
Protection & Detection, and Microsoft Entra ID sign-in — all with a password
fallback that can never lock you out.

Part of the **NextLVLHasH-HasHArch** org. Staged snapshot (nested git history,
build artifacts and secrets excluded).
